### Fixed

- Free space is now checked against the game's real size once extracted, not the package size. Game data is compressed inside a package and can take more than twice the room once unpacked, so a conversion could run out of space halfway. If there is not enough room, the app now stops before writing anything and tells you how much space the game needs.
- Choosing a PS4 package now says that only PS5 packages can be converted, instead of showing "Not a finalized image".
