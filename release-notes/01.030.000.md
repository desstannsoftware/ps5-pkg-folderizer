### Fixed

- Packing a dump into a `.ffpfsc` or `.exfat` image no longer fails with "Cannot create ....tmp" or "Cross-device link". The image is now built in a work folder on the target drive, then moved into place.
- The AMPR launch fix no longer fails with "Permission denied" on dumps.
- Packages whose file name has no title ID can now be packed into an image; the title ID is read from the package itself. Dumps without a title ID now say so before starting and suggest the Folder format.

### Changed

- Diagnostic logs (only sent when you turn diagnostics on) now go to a new server.
