# PKG Folderizer 01.048.000

Fixes console crashes after convert: AMPR no longer scans eboot/sce_module for import names (that path was SIGSEGV'ing after large extracts), and starting a convert frees cover-art memory first so big package layouts do not OOM-trap the app.

Install this if the title quit after "ampr imports" or while pressing Start on a large package.
