### Fixed

- Writing a large `.exfat` or `.ffpfsc` image no longer slows to a crawl and gets the app closed partway through. The image is flushed to disk every 256 MB instead of piling up in memory.
- Publishing to an external drive no longer fails with "No such file or directory" when its `homebrew` folder does not exist yet.
- Some large PS5 packages closed the app the moment conversion started. When a package's game image is laid out in a way the app cannot read safely, it now stops with an error message instead of crashing.
- The launch fix no longer fails with "Official libSceAmpr.sprx is missing from assets/ampr". The library is now built into the app instead of read from its install folder.

### Changed

- Games made of many small files spend most of their extraction time on per-file overhead. Small files are now sent to the helper without waiting, which may speed these games up, and progress lines appear every minute and show where the time goes.
- If the app closes unexpectedly, the last diagnostic lines that had not been sent yet are sent the next time it starts, so crashes can be traced.
