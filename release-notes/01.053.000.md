# PKG Folderizer 01.053.000

Fixes boot crashes (SIGSEGV at startup) that started after 01.051.

- Title heap is back to 384 MB. Reserving 512 MB at process start starved the OpenGL driver on many consoles (null+0x18 page fault while drawing the first frames).
- Keeps the 01.051 PFSC single-buffer open (large `.ffpfsc` without the doubled table) and the 01.052 parallel inflate race fix.

Update if the app dies as soon as it opens, or if you never got past the splash after 01.051 / 01.052.
