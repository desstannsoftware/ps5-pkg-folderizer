# PKG Folderizer 01.057.000

## Fixes
- Stops the intermittent startup crash caused by Mesa compiling the procedural backdrop shader (`SIGSEGV` at fault address `0x9` / `0x18`, often in `nir_build_imm`). The animated backdrop fill is temporarily disabled; the rest of the UI is unchanged.
- Richer crash reports for the next time something faults: breadcrumb trail of boot/work notes, build stamp, registers, RIP candidates, and a raw ucontext dump so reports can be symbolicated even when Prospero’s signal context RIP is wrong.

## Notes
- Update is recommended for everyone on 01.056 and earlier if the app sometimes fails to open.
