# PKG Folderizer 01.051.000

Crash fix for very large `.ffpfsc` images (for example Marvel's Wolverine).

- Opening a huge zlib PFSC no longer doubles the block-table in memory (~23 MB saved at peak on a ~190 GB image).
- Title heap raised to 512 MB so the UI and that table can coexist without an out-of-memory trap (which showed up as SIGILL on the system debug screen).
