# PKG Folderizer 01.047.000

Self-update no longer stalls while the package list is scanning — you can update as soon as the dialog appears, even right after launch. Starting a convert also refuses packages that are not a real PS5/PS4 image (wrong or incomplete `.pkg`), and the error now includes the file header bytes so bad downloads are easier to spot.

If Update said "Wait for the current convert to finish" while nothing was converting, install this and try again.
