# PKG Folderizer 01.054.000

Urgent fix for intermittent startup SIGSEGV (fault at 0x18 / 0x9, splash then crash).

- Title heap no longer reserves 384 MB before OpenGL starts. EGL/Mesa bring-up uses the system allocator; the convert heap is enabled only after the renderer and fonts are ready.
- Boot phases are tagged in crash reports (`boot-display`, `boot-renderer`, …) so the next fault is pinpointable.
- After a crash, the intro is skipped once to keep the recovery launch light.

Keeps 01.052 inflate race fix and 01.051 PFSC single-buffer open.

Update if the app still dies on the first open after an update.
