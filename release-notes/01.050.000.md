# PKG Folderizer 01.050.000

PS4 package convert progress and speed.

- The extract screen now shows real MB/s and GB for PS4 `.pkg` jobs (it was reading file counts as bytes, so speed looked stuck at "—").
- PFSC inflate reuses zlib per thread and batches more blocks; AES-XTS decrypts through a window on several cores; larger write chunks and fewer fsyncs.

Very large PS4 titles (for example Red Dead Redemption 2) still decrypt and zlib-decompress every byte — that path cannot match PS5 NAPS copy speed — but the meter should move honestly and the same job should finish sooner than on 01.048 / 01.049.
