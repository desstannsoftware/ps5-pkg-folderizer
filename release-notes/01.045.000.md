# PKG Folderizer 01.045.000

Fixes a crash at the end of Start on large games (for example Mortal Shell II / PPSA34008): after the package finished extracting, the AMPR launch fix could SIGSEGV while scanning a huge eboot.bin.

Also keeps the resume journal until post-extract steps finish, so a crash during the launch fix no longer forces a full re-extract of tens of gigabytes.

Update, then Start the title again — already-extracted files should resume.
