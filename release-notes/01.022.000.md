### New

- The app is now released as `PPSA99180.zip`, the app folder for `/data/homebrew/`. The `.ffpkg` image of the same build is still attached.

### Features

- Converts debug (FPKG) `.pkg` files into `/data/homebrew/<TITLE_ID>-app0` folders, compressed `.ffpfsc` images or plain `.exfat` images; you pick the format before each convert.
- `.ffpfsc` compression level: Fast, Balanced or Smallest. The finished screen shows how much space the image saved.
- Starts its bundled helper payload through etaHEN's ELF loader on every scan; nothing has to be sent by hand.
