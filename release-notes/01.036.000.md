### Added

- A conversion that stops partway, because the app closed or crashed or the drive filled up, continues where it stopped the next time you start the same package. Files already written are kept; only the rest is extracted. The Convert screen shows how much is already done. Cancelling still removes the partial files.

### Changed

- Folder is now the default output format and is marked as recommended.
- Choosing a retail PlayStation Store package now says plainly that only debug (FPKG) packages can be converted.

### Fixed

- Building an `.ffpfsc` or `.exfat` image could stop with "Short write while packing the image" even with free space left. If writing really fails, the message now says why: the drive is full, or a FAT32 drive cannot hold files over 4 GB.
