# PKG Folderizer 01.101.000

## Convert speed
- Image packing (exFAT / FFPKG / FFPFSC) prefers a different drive than the game dump when one has free space — same-disk packs were collapsing to ~1 MB/s in the field.
- Larger read chunks and dropping written pages from cache while packing so reads stay fast on one volume.

## Permissions / verify
- Re-open dump permissions before pack and before verify (fixes false “image holds N, the game 7” failures).
- Verify lists the game tree through the helper when the sandbox readdir is incomplete.
- Ext/USB work folders: CHMOD the parent before mkdir.
- USB homebrew dump scan retries after open_permissions on EACCES.
- Cache cleanup CHMODs locked staging trees before delete.
