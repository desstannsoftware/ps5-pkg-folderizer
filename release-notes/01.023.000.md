### Fixed

- Packages downloaded by homebrew stores (for example Orbis Store) no longer show greyed out with "Package not found".
- `/data` works without etaHEN's "Allow /data in sandbox" setting: the helper payload makes it visible to the app and removes that mount when the app closes.
- Free space is read through the helper, which fixes crashes on some firmware.

### Changed

- etaHEN is no longer required: any ELF loader on port `9021` with kstuff is enough.
- Extracted files are written by the helper outside the app's sandbox, to keep write speed from collapsing on large games.
- Each conversion starts by writing two 4 GB test files (one from the app, one through the helper) and logs their speed to `convert.log`.

### New

- **Send diagnostic logs** on the About screen, off by default. When turned on, the conversion log is uploaded to the developer over HTTPS so problems can be checked without FTP. See the README for what is sent.
