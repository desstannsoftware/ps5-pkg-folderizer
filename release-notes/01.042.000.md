# PKG Folderizer 01.042.000

Selecting huge FPKGs (Call of Duty, Metal Gear Solid Delta, and similar) no longer tries to open their full layout just to estimate size — that was still able to crash the app on 01.041.

This build also writes a short crash report when something fatal happens (signal or out-of-memory). The next launch uploads it so we can see what went wrong.
