### Added

- When a newer version is out, the app shows a window saying so, once per launch.
- Announcements from the developer appear in a window while the app is open, without restarting it. Each announcement is shown once.
- The developer can send a message to a single console, for example to follow up on a reported problem.

### Changed

- The console ID shown in About now comes from the console itself, so it stays the same after reinstalling the app or formatting the console. It is a one-way hash; the console's hardware ID is never sent. See the README for what the app sends.
