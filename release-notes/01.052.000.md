# PKG Folderizer 01.052.000

Fixes false "image did not check out" failures on large compressed `.ffpfsc` images.

- Parallel PFSC inflate no longer shares a `thread_local` zlib stream across workers (that race on 01.050 / 01.051 made random compressed blocks fail to decompress during verify).
- Each worker keeps its own stack inflater; PS4 extract still reuses one stream per thread safely.

If verify failed near a high block number after a long compress, update and pack again.
