### Added

- PS4 debug packages convert too, and the game list shows each entry's format: PS5 FPKG, PS4 PKG or Folder.
- New output formats: `.ffpkg` (UFS2) and `.ffpfs` (uncompressed PFS), next to Folder, `.ffpfsc` and `.exfat`.
- LZ4 asset packs: game data can be packed into the LZ4 volumes the AMPR emulator reads.
- Recommended settings are picked for each game, and after a convert the app asks whether the game booted so the recommendations get better.
- Batch queue: queue several games and convert them one after another, each with its recommended settings. The PS5 can power off when the queue is done.
- Browser remote: open the address shown in the app from a phone or computer on the same network to browse games with their covers, start or queue conversions and follow progress.
- Homebrew store in the browser remote: install and update our apps, PKG Folderizer included.
- Every packed image is read back and checked before it is kept; the source package is only deleted once that check passes.
- The AMPR launch fix recognises the emulator a game already ships and replaces older official builds.
- An opening plays the first time a new version starts. Press Cross to skip it.

### Changed

- Converts are much faster: packages are decompressed and written on four threads.
- The space a convert needs is read from the package's own file tables, so the estimate matches the unpacked game, LZ4 packs included. `.ffpfsc` estimates follow the chosen compression level, and the screen shows the space left once the convert is done.
- If the chosen drive is too small, a drive with room is offered. Press Down to open Advanced options.
- The Convert, Progress and Done screens are redesigned.

### Fixed

- Folder converts reach 100% instead of stopping at 80%.
- The PS5's address shows as soon as the app opens.
- Large game libraries no longer run out of memory while cover art loads during a convert.
